    Architecture du prototype

    Le frontend (HTML, CSS et JavaScript) est destiné à être hébergé sur AWS Amplify Hosting avec une adresse HTTPS publique.

    Limite du prototype : les tâches sont sauvegardées uniquement dans ce navigateur (localStorage), et non sur AWS. Pour obtenir un vrai service mobile connecté au Cloud, il faudra ajouter un backend AWS, par exemple une authentification Amazon Cognito et une API.
